# Canciones JA - Rorro Producciones

Aplicación web para mostrar y reproducir las canciones de JA (Jóvenes Adventistas) de la IASD Ypané 2026.

## Descripción

Este proyecto contiene una aplicación web interactiva con letras de canciones para presentaciones en reuniones de Jóvenes Adventistas. Incluye funcionalidades para navegar entre canciones, con diseño adaptado para proyecciones.

## Características

- **Interfaz intuitiva**: Menú principal con acceso rápido a todas las canciones
- **Presentación optimizada**: Diseñado para pantallas de proyección
- **Navegación fluida**: Botones para avanzar/retroceder entre canciones
- **Diseño responsivo**: Adaptable a diferentes tamaños de pantalla
- **Logos institucionales**: Incluye logotipos de JA y Conquistadores

## Archivos

- `1. Canciones con Guitarra JA.html` - Archivo principal con todas las canciones
- `images/` - Carpeta con logotipos e imágenes
  - `ja-logo.png` - Logo de Jóvenes Adventistas
  - `conquistadores-logo.png` - Logo de Conquistadores
  - `logo-iasd(negro).png` - Logo IASD

## Cómo usarlo

1. Abre el archivo `1. Canciones con Guitarra JA.html` en tu navegador web
2. Desde el menú principal, selecciona la canción que deseas mostrar
3. Usa los controles de navegación para cambiar entre canciones
4. Ideal para proyectar en reuniones o cultos

## Tecnologías

- Tailwind CSS
